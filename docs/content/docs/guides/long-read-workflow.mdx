---
title: Long-read workflow
description: Recommended command sequence for long-read runs that need posterior modeling and phasing.
---

Use the long-read path when:

- you have long cDNA or mRNA reads
- you can provide confident read-to-gene assignments
- you want to classify mismatch behavior and optionally phase loci across reads

## Recommended workflow

### 1. Get read to gene assignments with isoquant
```bash
# install isoquant 
pip install isoquant

# run isoquant for example with a single cell pacbio bam file
isoquant.py -d pacbio \
  --bam $BAM \
  --reference $FA \
  --genedb $GTF \
  --complete_genedb --output ${OUT} -t 8 \
  --read_group tag:CB \
  --splice_correction_strategy default_pacbio
```

### 2. Get pileup VCF with cellsnp-lite
```bash
# install cellsnp-lite
conda install -c bioconda cellsnp-lite

# run cellsnp-lite mode 1b with a pacbio bam file
cellsnp-lite -s $BAM \
  -O $OUT \
  -p 8 \
  --minMAF 0.05 \
  --minCOUNT 10 \
  --cellTAG None \
  --UMItag None \
  --chrom chr1,chr2,chr3,chr4,chr5,chr6,chr7,chr8,chr9,chr10,chr11,chr12,chr13,chr14,chr15,chr16,chr17,chr18,chr19,chr20,chr21,chr22,chrX,chrY,chrM
```

### 3. Annotate reads
```bash
mola read annotate \
  -b $BAM \
  --repeat_bed $REP_BED \
  --gff3 $GFF3 \
  --read_assignments $IQ \ # read assignment from isoquant
  --write_read_info
```

### 4. Map mismatches to reads
```bash
mola mut map \
  -b $BAM \
  --ref_vcf $REFVCF \
  --pileup_vcf $CELLSNP_VCF \ # pileup VCF from cellsnp-lite
  -r $READS \ # reads directory from step 3
  --min_minor_allele 1 \
  -t 2 \
  -o $OUT \
  --tmp_dir $TMP # tmp directory from step 3
```

### 5. Posterior distribution modeling
```bash
mola infer posteriors \
  -s tables/sites_stranded.tsv.gz \
  -u tables/sites_unstranded.tsv.gz \
  --tech pacbio \
  -o $OUT
```
This steps basically to classify mismatches based on the posterior probability of beta-binomial mixture distributions.
